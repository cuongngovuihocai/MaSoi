## 🚀 Cách tải ảnh vào thư mục này:
1. Bạn có thể bấm nút **Upload file / Tải file** (biểu tượng hình kẹp ghim / ô tải file trong khung Chat này) hoặc kéo thả trực tiếp các file ảnh vào khung Chat.
2. Hệ thống sẽ nhận diện và đưa file vào thư mục `/public/cards/`.
3. Trò chơi sẽ tự động ưu tiên hiển thị hình ảnh thẻ bài của bạn! Nếu file ảnh nào chưa có, trò chơi sẽ tự động dùng hình minh họa mặc định.
